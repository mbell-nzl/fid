# fid

Local-first, agent-first issue tracker for AI-assisted software development.
SQLite-backed CLI.

A fid is a tapered hand tool used to open up tightly-laid rope so the
strands can be worked separately. Pairs with whet (sharpening) as a
workshop-drawer set.

## Status

Pre-implementation. Design spec and domain glossary are complete. Workflow
scaffolding is in place. Specs are being filled progressively from
`scaffold/initial-spec.md`.
