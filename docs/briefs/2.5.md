## Approved design

- **Where and what.** `loops/loop.py`, Python 3 standard library only,
  under 150 lines (enforced by a test), fid's own copy. Task 3.3 promotes
  it to the kit. Prompts live beside it in `loops/prompts/`. Agent commands,
  models, actors and the repository for gh come from environment variables
  with defaults documented in `loops/README.md`.
- **Shape.** Claim, act on kind, repeat. Exit 0 at `none`, saying why from
  `waiting`. Every fid call uses `--json`. Refuse an unsupported contract
  version at startup. Stop loudly (nonzero, reply quoted) on an unknown
  `kind` or `waiting.kind`, malformed JSON, a missing declared field, empty
  output or an unexpected nonzero exit, following the contract and D2.
- **Two worktrees, two actors, one loop.** The build worktree keeps its
  handed-off task for rework; its `next` returns `none`, waiting for review.
  Keep a detached review worktree, peek `next` there and claim only review
  work there as the reviewer. Claim everything else in the build worktree
  as the builder. fid refuses builders reviewing their own tasks. Defaults:
  `agent:sol-builder` and `agent:sol-reviewer`, both `openai/gpt-6.1-sol`
  through `codex exec`.
- **The loop does fid's, git's and gh's steps; agents do the work.**
  - `new`: `fid start`, builder agent, `fid check`, push, draft PR with the
    agent's report as body, `fid handoff`.
  - `rework`: fixer agent with open findings and rework-allowance guidance.
    For `cause: default-conflict`, merge the default branch first. Check,
    push and hand off again on the same PR.
  - `resume`: continue as the kept work requires; pass `answer` (question
    and text) to the agent.
  - `review`: check out the hand-off head in the review worktree; run the
    reviewer for `required_profiles` and `stream`; record its JSON with
    `fid review record`. fid posts the PR comment. On APPROVE, `gh pr ready`
    starts CI. Mark reads `fid status` for a separate review or his approval,
    and merges. The loop never merges.
  - After each item, `fid backup`. At startup and `none`, batch `fid done`,
    reporting every outcome.
- **Briefs.** Approved briefs live in `docs/briefs/<task>.md` (RESET row ID,
  else fid ID), named by `spec_md_path`. Pass ID, title, acceptance criteria
  and spec path from `fid show --json`. Declare these show fields in the
  contract with goldens; this addition keeps `fid-cli.v1`. A builder who
  finds an unsettled design parks with `fid park --waiting "<question>"`,
  using the loop-supplied hold ID, instead of guessing. The loop sees the
  park and moves on.
- **Heartbeat.** A thread renews the hold every
  `heartbeat_interval_seconds` while an agent runs. `hold-not-current`
  stops the loop loudly.
- **Interrupts.** Agent failure, a usage limit or Ctrl-C parks the build
  hold with `fid park --interrupted --reason ...` and exits nonzero. The
  next run receives it as `resume` (V4).
- **Codex sandbox.** Give the builder the worktree's git directory as a
  writable root: Codex has failed to commit without it. If changes remain
  uncommitted, stop loudly; never commit for the agent.
- **Lane.** RESET says Standard, but the V9 Makefile verifier is Assured
  through `.fid.toml`'s fmt `defined_by`. Expect fid to raise the floor at
  hand-off. Report Assured, with `## Rollback`.
