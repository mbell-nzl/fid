## Purpose

This file is the finite set of validation assertions that must be true when
Phase 19 is complete. The validation contract specifies **what must be
proven**; the QA plan (QA Lead) specifies **how to prove it**.

Phase 18 made workflow *structure* data. Phase 19 makes it *authorable*:
`fid workflow define` writes user workflows as journal events into the same
projected workflow tables, `fid workflow assign` binds a workflow to an issue
kind or to the project, `fid workflow list` reads them back in every supported
format, and the `escalation-default` workflow (PRD-WF-005a) is seeded as
system reference data.

If a required validation assertion cannot be satisfied, stop and escalate
instead of weakening the assertion or silently adapting the spec.

## Numbering

- IDs use `VAL-NNN`, scoped to Phase 19, sequential from `VAL-001`.
- Retired or superseded assertions stay in the table with status and
  rationale; IDs are not reused.
- **VAL-027..VAL-070 were added at the 2026-07-26 refinement (DEC-091)** to
  unbundle independent observables (QA-BLK-03) and close coverage gaps
  (QA-BLK-04). VAL-001, 003, 004, 007, 009, 010, 011, 014, 015, 016, 017,
  018, 019, and 023 were **narrowed to one observable each**; every behavior
  they previously carried is now owned by exactly one assertion in the same
  task window. Nothing was removed, weakened, or moved between tasks.

## Inventory-Assertion Evidence Convention (DEC-094)

**VAL-031, VAL-042, VAL-069, and VAL-070** are proven by the *absence* of
matches in a static `rg` inventory over non-test sources. For all four:

- The passing result is **no output and exit 1** — `rg` exits non-zero when it
  finds nothing. Exit 0 with printed matches is the **failing** result.
- The completion report, review, or final review records
  `PASS (no match) - exit 1 (no output)` against the exact command, and says
  which assertion the no-match proves. Recording `exit 0 (no output)` for a
  search command is a DEC-086 evidence violation and a hard stop, regardless of
  whether the underlying observable happens to hold (Phase 19 TRG-19-001).
- The command is recorded verbatim, including every `--glob` exclusion. A
  narrower path list or a dropped exclusion is a substituted command, not
  evidence.

This does not relax any pass criterion: the QA Lead re-runs each inventory
independently in its owning window.
