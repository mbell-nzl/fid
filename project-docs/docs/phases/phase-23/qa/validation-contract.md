## Purpose

This is the finite set of assertions that must be true when Phase 23 is
complete. The contract specifies **what must be proven**; the QA plan specifies
**how**. If a required assertion cannot be satisfied, stop and escalate rather
than weakening it.

## Numbering

IDs are `VAL-NNN`, sequential from `VAL-001`, scoped to this phase. Retired or
superseded rows stay in the table with rationale; IDs are never reused.
