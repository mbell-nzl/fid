## Purpose

This is the finite set of assertions that must be true when Phase 23 is
complete. The contract specifies **what must be proven**; the QA plan specifies
**how**. If a required assertion cannot be satisfied, stop and escalate rather
than weakening it.

## Numbering

IDs are `VAL-NNN`, allocated sequentially from `VAL-001` and scoped to this
phase. Rows are grouped topically, so a later-allocated ID may appear out of
numeric order; `VAL-074` sits with the Concern rows, and the five rows added on
2026-09-15 sit with their subjects: `VAL-075` with the baseline rows, `VAL-076`
with the portability rows, `VAL-077` with the evidence-linking rows, `VAL-078`
with the Attention rows, and `VAL-079` with the audit rows. Retired or
superseded rows stay in the table with rationale; IDs are never reused. The
contract now holds 79 assertions: 75 deterministic and 4 Human.
