complete. The contract is the specification; the QA plan is the test plan.
If a required assertion cannot be satisfied, stop and escalate. Never weaken
it.

## Shared Terms

- **Observing leaf** (contract section 2, DEC-278): `gate.register`,
  `envelope.create`, `envelope.complete`, `claim.acquire`, `run.start`,
  `run.close`, `run.abandon`, `run.observe-budget` (when `measurement_ref`
  is non-null), `gate.run`, `evidence.evaluate`, `review.record`,
  `concern.record`, `concern.dispose`, `deviation.record`,
  `decision.record-reference`, `human-outcome.record`,
  `requirement.record-reference` and `requirement.link`. `evidence.link` is
  not one: it copies the subject's recorded repository (VAL-034).
- **Observing mutation:** an observing leaf that takes `--idempotency-key`.
  That is every observing leaf except `evidence.evaluate`.
- **Keyed leaf:** a live leaf with `--idempotency-key`, minus
  `export import`, which uses an install marker and no request digest. There
  are 49, regenerated by inventory R16.
- **SourceInput leaf:** `decision.record-reference`,
  `requirement.record-reference`, `human-outcome.record`, `concern.record`,
  `deviation.record`, `review.record`, `envelope.create` and
  `run.observe-budget`. Its **Source positions** are every descriptor field
  typed `SourceInput`, enumerated from the descriptor registry with a
  completeness check.
- **Expectation leaf:** `review.record`, `run.start`, `run.close`,
  `run.abandon` and `gate.run`.
- **Independent observation:** the test's own `git rev-parse HEAD`,
  `git rev-parse HEAD^{tree}`, `git status --porcelain` and the SHA-256 of
  the absolute worktree root. It is never fid output.
- **Plain copy:** a recursive copy of the whole worktree, `.git` included,
  to a new path with no import binding. It is observable, and its
  `worktree_id` differs.
- **Corpus:** a table-driven fixture whose rows are enumerated from the
  owning registry (an inventory command or a code registry), not from a
  hand-picked list. Adding a registry member without a row fails a test.
