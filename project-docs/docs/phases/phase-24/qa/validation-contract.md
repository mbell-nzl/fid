## Purpose

This file is the finite set of assertions that must be true when Phase 24 is
complete. The contract is the specification; the QA plan is the test plan.
If a required assertion cannot be satisfied, stop and escalate. Never weaken
it.

## Numbering

`VAL-NNN` is phase-scoped. VAL-044, VAL-047 and VAL-056 restate Phase 23
VAL-060 and VAL-073 (contract section 11). They are not weakened.

## Shared Terms

- **Observing mutation:** a leaf that observes the repository under contract
  section 2. These are the 17 changed leaves of contract section 4 plus the
  judgment leaves that already record an observed Event repository.
- **SourceInput leaf:** `decision.record-reference`,
  `requirement.record-reference`, `human-outcome.record`, `concern.record`,
  `deviation.record`, `review.record`, `envelope.create` and
  `run.observe-budget`.
- **Expectation leaf:** `review.record`, `run.start`, `run.close`,
  `run.abandon` and `gate.run`.
- **Independent observation:** the test's own `git rev-parse HEAD`,
  `git rev-parse HEAD^{tree}` and `git status --porcelain` of the fixture
  worktree. It is never fid output.
- **Corpus:** a table-driven fixture that enumerates its rows from the owning
  registry (the inventory command), not from a hand-picked list. Adding a
  registry member without a row fails a test.
