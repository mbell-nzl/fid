## Purpose

This accepted contract is the finite set of assertions that must hold when
Phase 20 completes. It validates `../contracts.md`. The QA plan defines the
execution procedure and may request clarification, but it may not weaken an
assertion. All rows remain `Draft` until QA-plan acceptance.

## Numbering

- IDs are phase-scoped and sequential from `VAL-001`.
- A pre-execution scope change removes or supersedes a draft row; `CARRY-FORWARD`
  is an outcome for accepted work that was attempted but not satisfied.
