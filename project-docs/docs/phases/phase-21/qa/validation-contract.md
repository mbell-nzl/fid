## Purpose

This is the finite set of observable assertions for the Heavy Phase 21 slice.
The exact behavior is fixed by `../contracts.md` and DEC-154; a QA plan may
improve evidence strategy but cannot weaken, combine, or silently re-scope an
assertion. Each row has one validator. Group 2 is gated by VAL-028.

## Coverage Notes

- Phase 21 implements bounded parts of target P0 requirements. Assertions name
  each qualifying state and the adjacent deferred state; target requirements
  for recovery, Stops, Attention, budget consumption, Review/Human Outcomes,
  parallelism, import parity, attestation, and telemetry are not claimed.
- `Routine` appears in no assertion because it is external kit risk-lane
  language, not a fid entity or capability.
- VAL-036 is the only Human assertion. QA Lead must preserve it as one
  checklist observable and record the exact terminal fixture used.
- The QA plan must map every row to one deterministic, mid-phase, or Human step
  and must retain VAL-028 as a hard Group 2 dispatch prerequisite.
