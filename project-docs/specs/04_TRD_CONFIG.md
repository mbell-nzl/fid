# TRD CONFIG — fid

> `.fid/` directory structure, configuration file formats, and
> gitignore policy. Extracted from `scaffold/initial-spec.md` §11.1
> and scattered references in the TRD and initial spec.

---

## 1. `.fid/` Directory Structure

`fid init` creates the `.fid/` directory at the project root with the
following layout:

```
.fid/
├── journal/
│   └── YYYY-MM-DD.jsonl       # append-only journal; one file per day
├── config.toml                # project configuration
├── pricing.toml               # model pricing data
├── fid.sqlite                 # derived query cache (gitignored)
└── .gitignore                 # ignores fid.sqlite
```

| Path | Purpose | Committed to git? |
|---|---|---|
| `journal/YYYY-MM-DD.jsonl` | Source of truth. Append-only event journal. | Yes |
| `config.toml` | Project-scoped configuration. | Yes |
| `pricing.toml` | Model pricing data (ships with defaults, user-overridable). | Yes |
| `fid.sqlite` | SQLite query cache. Derived projection of the journal. Deletable and rebuilt via `fid rebuild`. | No (gitignored) |
| `.gitignore` | Contains `fid.sqlite` | Yes |

---

## 2. `config.toml`

Project-scoped configuration. Created by `fid init` with sensible
defaults.

```toml
# Project identity
[project]
prefix = "FID"                 # issue ID prefix; set at init

# Export settings (v0.4)
[export]
markdown_root = "./docs/"      # output directory for fid export
layout = "whet"                # 'whet' | 'flat' | 'custom'
banner = true                  # emit "generated by fid" banner in exported files

# Future sections (not present in v0.4 config):
# [sync]                       # v0.5+: canonical = "db" | "md", auto_export = true | false
```

### 2.1 Sections

| Section | Version | Keys | Notes |
|---|---|---|---|
| `[project]` | v0.1 | `prefix` | Set at `fid init --prefix <PREFIX>`. Immutable after init. |
| `[export]` | v0.4 | `markdown_root`, `layout`, `banner` | Controls `fid export` behavior. |

Compatibility policy: additive sections only. No removal without a
migration path.

## 3. `pricing.toml`

Model pricing data used to compute `agent_runs.cost_usd` at run
close. Ships with defaults for current Anthropic/OpenAI/Google models;
user-overridable.

```toml
# Each model entry maps to (in_per_mtok, out_per_mtok) in USD.
# cost_usd = (tokens_in * in_per_mtok + tokens_out * out_per_mtok) / 1e6

[models.claude-opus-4-7]
in_per_mtok = 15.0
out_per_mtok = 75.0

[models.claude-sonnet-4-6]
in_per_mtok = 3.0
out_per_mtok = 15.0

[models.claude-haiku-4-5]
in_per_mtok = 0.80
out_per_mtok = 4.0

# Add custom models as needed:
# [models.my-custom-model]
# in_per_mtok = 5.0
# out_per_mtok = 25.0
```

### 3.1 Pricing Behavior

- Pricing is **snapshot** on each `agent_runs` row at run end. This
  preserves audit trail across price changes.
- If a model is missing from `pricing.toml` at run close, `cost_usd`
  is left NULL and a warning is logged. No silent guessing.
- Users can add or override any model entry.

---

## 4. `fid init` Behavior

`fid init` performs:

1. Creates `.fid/` directory.
2. Creates `.fid/.gitignore` containing `fid.sqlite`.
3. Creates `.fid/config.toml` with `[project] prefix = <PREFIX>`
   (default: project directory name, uppercased).
4. Creates `.fid/pricing.toml` with default model pricing.
5. Creates `.fid/journal/` directory (empty).
6. Creates `.fid/fid.sqlite` with the current schema applied via
   migrations.
7. Seeds the `roles` table with the default profile role list.
